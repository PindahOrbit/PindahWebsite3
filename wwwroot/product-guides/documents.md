# Documents

## Executive Summary

Documents provides a central place to store, organise, and work with files across your organisation. Create folders, upload documents, and share files linked to other areas of the system such as projects, customers, or insurance submissions.

---

## Who This Is For

- All staff who need a shared file library
- Administrators managing document templates
- Teams attaching evidence to business records

---

## Key Capabilities

- Folder structure
- File upload and download
- Document creation and editing
- Search and organisation

## Getting Started

Open **Documents** in the sidebar to access your organisation’s document library.

---

## Browsing Documents

Navigate folders in the left panel. Click a folder to see its contents. Use search to find files by name.

![Screenshot: Folder browser — placeholder]

---

## Creating Folders

1. Select the parent folder (or root).
2. Create a new folder with a clear name — for example by department, year, or project.
3. Set permissions if your organisation restricts folder access.

![Screenshot: Create folder — placeholder]

---

## Uploading Files

1. Open the target folder.
2. Choose upload and select files from your computer.
3. Wait for upload to complete and verify the file appears in the list.

![Screenshot: File upload — placeholder]

---

## Working with Documents

Open a document to preview or download. Where supported, create new documents from templates directly in the browser.

Documents attached elsewhere in the system (for example on an insurance submission) also appear in linked records — use Documents for general storage and those screens for context-specific files.
